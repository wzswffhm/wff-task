# 安全清理 NTFS 工作目录

请修改 `src/` 里的 WinTask.exe。它接收工作目录根路径和一个 JSON 文件，JSON 是要删除的相对文件名数组。

删除前先把整份清单检查完：路径必须留在根目录内，不能经过重解析点，目标必须是普通文件，且 NTFS 硬链接数必须为 1。空清单和普通文件删除要正常工作；只要清单中有一项不合法，就返回验证错误，并且工作目录中的任何文件都不能被改动。

命令行保持为 `WinTask.exe <根目录> <manifest.json>`。验证失败返回 2，输出 `{"status":"error","kind":"validation"}`；普通 I/O 失败返回 3；成功返回 0 并输出 `{"status":"ok"}`。
