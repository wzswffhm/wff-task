# deliverables/ — 解析材料产出区

本目录存放**对某份材料做解析/分析后的产出**，避免污染仓库根目录与其他题包目录。

## 命名规则

目录名 = `<YYYY-MM-DD>_<材料文件名（去扩展名）>`，材料名部分**保持原名原样**。

```
外部材料：      windwos-第二版.pdf
                  ↓
deliverables/
└── 2026-09-29_windwos-第二版/       # 日期 + 材料主名（去扩展名）
    └── （该材料的解析产物，按内容合理命名）
```

规则要点：

- **日期取产出当日**（用 `date +%F` 取真实值，不凭记忆推算）。
- **材料名保持原样**，含原始拼写（`windwos` 是原件的拼写，不要"纠正"成 `windows`）。
- **一材料一目录**，目录内产物按内容命名，不强制与材料同名。

## 与仓库其他目录的分工

| 目录 | 用途 |
|---|---|
| `deliverables/` | **解析材料产出**（文档为主，人可读） |
| `OBM/` `harbor-16/` `harbor-sota/` 等 | **题包类型目录**（机器可执行，一题一子目录） |
| `skills/` | 唯一的 skill 目录 |

> 根目录只保留：`README.md`、`.gitignore`、`deliverables/`、`skills/` + 已登记的题包类型目录。
