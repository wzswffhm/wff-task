## python 实跑 vs Docker 跑 verifier 的区别（用户提问）

- Docker：基础镜像按 digest 固定 + 离线依赖，任何机器可复现；`--network=none` 能真正证明离线可构建（暴露 Dockerfile 里 apt/pip/curl 的隐式联网）；Linux 语义（fork、os.kill、文件锁、权限位）与训练/评测平台一致；从干净 HEAD 应用 Agent patch。
- 本地 python 实跑：受本机平台影响（我这里是 Windows + Python 3.13，无 fork/os.kill、NTFS 无可执行位、CRLF 换行），无法验证联网行为，判分环境不一致 → 只能作为等价近似证据，规范仍要求 Docker 下重跑 NOP/Oracle。
