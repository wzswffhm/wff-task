# 真实法律材料：类型、字段口径与脱敏

## 1. 源文件原则

- **该场景真实的交付物是什么，就用什么源文件。**
- **必须为真实或高仿真数据**；不得要求模型凭空猜测法规条款、政策口径、职责分工或统计数据。
- 数量没有限制，总大小在 **20 GB** 以内（计入整批）。
- 放入 `environment/input_files/`，容器内映射为 `/app/input_files/`（只读，`chmod -R a-w`）。

## 2. 常用材料类型与字段口径

| 材料 | 常见格式 | 关键字段 / 口径（instruction.md 中须列表说明） |
|---|---|---|
| 合同 | .docx / .pdf | 当事人、标的、金额、付款方式与期限、违约责任、争议解决、签署日期 |
| 判决/裁定书 | .pdf | 案号、法院、当事人、争议焦点、查明事实、裁判理由、判决主文 |
| 起诉状 / 答辩状 | .docx | 诉讼请求、事实与理由、证据目录、标的额 |
| 工商档案 | .pdf / .xlsx | 主体名称、统一社会信用代码、注册资本、股东与出资比例、变更记录 |
| 银行流水 | .csv | 交易日期、对方户名、摘要、金额、余额；**须注明币种与是否含冲销** |
| 往来邮件/函件 | .eml / .md | 发件人、收件人、日期、正文、附件名 |
| 监管规定摘编 | .md / .pdf | 文件名称、发文字号、施行日期、效力状态、条文 |
| 财务/合同台账 | .xlsx | 合同编号、签订日期、对方、金额、履约状态 |
| 庭审笔录摘要 | .docx | 时间、参与人、陈述要点、举证质证意见 |

**instruction.md 中的源文件表写法（示例）**：

```markdown
| 文件 | 说明 |
| --- | --- |
| `买卖合同.pdf` | 甲乙双方 2024 年 3 月签订的设备买卖合同，含价款、交付期与违约金条款 |
| `付款流水.csv` | 2024 年全年付款记录，UTF-8，含表头。字段依次为 `流水号`、`付款日期`、`付款方`、`收款方`、`金额`、`币种`、`是否冲销`。`是否冲销` 取值为 `是`/`否`，`金额` 单位为元 |
| `往来邮件.md` | 双方就迟延交付的交涉记录，共 6 封 |

两份材料对交付日期记载不一致时，一律以 `买卖合同.pdf` 约定的日期为准。
```

> **口径冲突要在任务书里显式给出裁决规则**，否则模型无法判断——这与"埋冲突看模型是否澄清"的弱点题不同，常规题必须给出裁决依据。

## 3. 脱敏规则（强制）

**必须移除或替换**：

| 类别 | 示例 | 处理 |
|---|---|---|
| 自然人姓名 | 真实姓名 | 替换为"张某""李某"或化名 |
| 身份证号 | 18 位号码 | 替换为 `110***********1234` 或直接删除该列 |
| 手机号 | 11 位号码 | 替换为 `138****0000` |
| 银行账号 / 卡号 | 长数字串 | 保留后 4 位，其余掩码 |
| 真实企业涉密信息 | 未公开财务数据、内部编号 | 替换为虚构企业名（如"A 公司"）+ 合理数量级 |
| 地址 | 精确到门牌 | 保留到区一级 |

**必须保留（否则模型无法对照核验或无法计算）**：

- 计算所需的金额、利率、期限、比例；
- 判断法律适用所需的日期（合同签订日、履行期、诉讼时效起算点）；
- 结构对照所需的条款编号、层级、章节名；
- 用于溯源的文献/案号（**虚构案号必须整体虚构且内部自洽**，不得套用真实案号）。

> **过度脱敏同样是错误**：删掉用于对照的核验证据（如把金额全抹掉），会导致题目不可解。

## 4. 脱敏自检

```bash
# 身份证 / 手机号 / 银行卡残留扫描（命中即需处理）
grep -rnoE "[0-9]{17}[0-9Xx]|1[3-9][0-9]{9}|[0-9]{16,19}" environment/input_files/ | head -50

# 常见真实姓名残留（按实际材料补充词表）
grep -rn "真实姓名1\|真实姓名2" environment/input_files/ || echo "OK"

# 文件编码与表头检查
file -i environment/input_files/*
```

**交付物侧的脱敏**是另一回事：任务书可要求"对外文书不得暴露身份证号、手机号"，并由 rubric 的 negate 条目判分（命中即扣 10 分）。

## 5. 交付物命名规范

- 以**题目编号为前缀**：`<TASKID>_法律意见书.docx`。
- **不加日期、时间戳、版本号**等动态成分；业务上需含日期的把具体字符串写死。
- `required = true` 的交付物写**精确文件名**，禁止 glob。
- 文件名在 **六处逐字节一致**：instruction.md / `deliverables.path` / `artifacts` / `solution/golden_output/` / `tests/__golden_output/` / criterion description。
