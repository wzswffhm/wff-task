## 提示词 level 策略（硬规则）

培训里 instruction 有 **level0–level4**。默认 **一律从 level4 开做**，不走 level0→1→2→3 递进试水。

| 阶段 | 做法 |
|------|------|
| 出题 | 只写 **level4** 作为首版 `instruction.md`；禁止先从低 level 试水再升级 |
| 校准（baseline / oracle；**smoke 可不跑**） | 用**当前锁定 level** 提示词验证 |
| **校准不通过** | **直接换题重新开始**（换 feature / 换模块 / 换仓）；禁止为凑校准降到 level2 及以下 |
| **校准通过** | 冻结**当前 level** 提示词、workspace、tests、solution 与镜像修订；可做一次无异常 smoke，随后用同一修订运行一个或多个完整 16 次 job |
| 每个 16 次 job | 记录完整结果，作为 `16×N` 候选池的一部分；不得提前结束仍在运行的 Trial |
| 候选池中已可选出 16 条（`<1`≥13 且 `=1`≥1） | 固化选样 manifest，停止难度试跑；每条列出来源 job 和 trial ID |

**提示词变更边界：** 不因某一批的零星 reward 分布改写提示词、降级、换题或提前终止容器。
但一个完整、有效的 16-trial job 若 16 条全部为 `reward=0`，可按用户规则改写提示词并新建
冻结修订；新修订必须重新做 baseline+Oracle，且新旧修订的 Trial 不得混入同一选样集。校准失败、
明确的题目/验证器缺陷或用户另行要求也必须新建修订后重校准。

「验证」在本条 = **baseline + Oracle**（同一冻结修订；**smoke 非必须**）。校准过了再开 16。

**换题 / 换仓目录铁律：** 凡需 **重新选项目** 或 **降 level 重开** 时，**禁止覆盖旧目录**——必须按下方「任务目录命名」**新建带时间戳的目录**再从头做。
