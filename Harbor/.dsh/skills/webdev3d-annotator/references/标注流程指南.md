# 标注流程指南

## 概述

本指南详细说明Webdev+3D前端产物人工标注的标准流程，帮助标注员高效、准确地完成标注任务。

## 流程步骤

### 第一步：需求分析（5-10分钟）

1. **阅读query.md**
   - 仔细阅读用户需求描述
   - 理解用户的核心目标和期望效果
   - 记录关键需求点（3-5个）

2. **需求合理性判断**
   - 检查需求是否清晰明确
   - 检查需求是否可执行
   - 检查需求是否有实际价值
   - 如果需求不合理，填写依据后终止流程

3. **需求分解**
   - 将需求分解为具体的功能点
   - 为每个功能点设定评估标准
   - 建立需求与功能的映射关系

### 第二步：产物加载（2-5分钟）

1. **打开产物**
   - 在新标签页打开HTML文件
   - 确认页面加载正常
   - 检查是否有加载错误

2. **初始检查**
   - 3D场景是否渲染
   - 基本交互是否可用
   - 是否有明显的错误提示

3. **环境确认**
   - 记录浏览器类型和版本
   - 记录设备性能（如适用）
   - 记录网络环境（如适用）

### 第三步：深度体验（15-20分钟）

1. **功能体验**
   - 按照用户需求中的描述，逐一测试每个功能
   - 记录功能的实际表现
   - 与需求要求进行对比

2. **交互测试**
   - 测试所有交互方式（键盘、鼠标、触摸等）
   - 检查交互响应速度
   - 检查交互逻辑的完整性

3. **性能观察**
   - 观察页面流畅度
   - 注意是否有卡顿现象
   - 记录帧率变化（如可能）

4. **错误记录**
   - 记录所有错误信息
   - 记录异常行为
   - 截图保存关键问题

### 第四步：维度评估（20-30分钟）

1. **提示词匹配度评估**
   - 对照用户需求，检查每个要求是否被满足
   - 记录缺失的元素或特效
   - 记录风格偏离的地方

2. **功能与交互评估**
   - 评估镜头控制的合理性
   - 评估动画效果的流畅度
   - 评估交互逻辑的完整性

3. **产物技术质量评估**
   - 检查模型是否有穿模、破面等问题
   - 检查材质和渲染是否正常
   - 检查性能是否达标

4. **美学与体验评估**
   - 评估光影效果
   - 评估色彩搭配
   - 评估整体布局

5. **其他维度评估**
   - 根据具体任务补充评估维度
   - 记录其他值得注意的问题

### 第五步：问题定位（10-15分钟）

1. **问题分类**
   - 将问题按维度分类
   - 按严重程度排序
   - 确定核心问题和次要问题

2. **精确定位**
   - 为每个问题提供具体的位置描述
   - 说明问题出现的条件
   - 提供截图或录屏证据

3. **影响评估**
   - 评估每个问题对整体体验的影响
   - 确定问题的严重程度（轻微/中等/严重）
   - 判断是否影响核心功能

### 第六步：备注填写（10-15分钟）

1. **维度备注**
   - 为每个评估维度填写1-2句具体备注
   - 包含问题描述、证据定位、影响评估
   - 使用专业、客观的语言

2. **补充说明**
   - 记录其他维度的问题
   - 提供改进建议（如适用）
   - 说明特殊情况（如适用）

3. **质量检查**
   - 检查备注是否具体、有证据
   - 避免使用模糊、主观的表述
   - 确保备注能让复核者理解

### 第七步：核对保存（5分钟）

1. **内容核对**
   - 检查所有字段是否填写完整
   - 检查评估结果与备注是否一致
   - 检查是否有遗漏的问题

2. **格式检查**
   - 检查文字表述是否清晰
   - 检查是否有错别字
   - 检查格式是否规范

3. **保存提交**
   - 保存当前标注作业
   - 交由用户统一确认
   - 等待用户授权后提交

## 时间分配建议

| 步骤 | 建议时间 | 优先级 |
|------|----------|--------|
| 需求分析 | 5-10分钟 | 高 |
| 产物加载 | 2-5分钟 | 中 |
| 深度体验 | 15-20分钟 | 高 |
| 维度评估 | 20-30分钟 | 最高 |
| 问题定位 | 10-15分钟 | 高 |
| 备注填写 | 10-15分钟 | 高 |
| 核对保存 | 5分钟 | 中 |

**总计时间**：约60-100分钟

## 注意事项

1. **不要跳过步骤**
   - 每个步骤都有其重要性
   - 跳过步骤可能导致遗漏问题

2. **保持客观**
   - 基于事实进行评估
   - 避免个人偏好影响判断

3. **注重细节**
   - 小问题可能影响整体体验
   - 详细记录有助于改进

4. **及时记录**
   - 发现问题立即记录
   - 避免事后遗忘细节

5. **保持沟通**
   - 遇到不确定的问题及时沟通
   - 需要时寻求技术支持

## 常见问题处理

### 问题1：产物加载缓慢
**处理方法**：
1. 等待足够时间让产物完全加载
2. 记录加载时间
3. 如果超时（>30秒），记录为加载异常

### 问题2：功能无法测试
**处理方法**：
1. 检查操作是否正确
2. 尝试不同的交互方式
3. 如果确认功能异常，记录具体现象

### 问题3：性能问题难以量化
**处理方法**：
1. 使用主观感受描述（如"明显卡顿"）
2. 记录卡顿出现的场景
3. 如果可能，使用性能监控工具

### 问题4：需求理解有歧义
**处理方法**：
1. 尝试从上下文推断
2. 基于最常见理解进行评估
3. 在备注中说明可能的歧义
