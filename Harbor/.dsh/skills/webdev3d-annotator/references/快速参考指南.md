# 快速参考指南

## 概述

本指南用于快速定位Webdev+3D前端产物标注中的常见问题，帮助标注员高效完成标注任务。

## 快速检查清单

### 1分钟快速检查

- [ ] 页面能否正常加载？
- [ ] 3D场景是否渲染？
- [ ] 基本交互是否可用？
- [ ] 是否有明显错误？

### 5分钟快速检查

- [ ] 核心功能是否实现？
- [ ] 主要交互是否正常？
- [ ] 视觉效果是否符合需求？
- [ ] 性能是否流畅？

### 10分钟快速检查

- [ ] 所有需求是否满足？
- [ ] 所有功能是否正常？
- [ ] 所有交互是否响应？
- [ ] 所有效果是否正确？

## 常见问题快速定位

### 问题1：页面无法加载

**可能原因**：
- 网络连接问题
- 浏览器兼容性问题
- HTML文件损坏
- 资源加载失败

**快速检查**：
1. 检查网络连接
2. 尝试刷新页面
3. 更换浏览器
4. 检查控制台错误

**快速解决**：
- 如果是网络问题，等待后重试
- 如果是兼容性问题，更换浏览器
- 如果是文件问题，重新下载

### 问题2：3D场景不渲染

**可能原因**：
- WebGL不支持
- 显卡驱动问题
- 浏览器设置问题
- 资源加载失败

**快速检查**：
1. 检查浏览器WebGL支持
2. 检查显卡驱动
3. 检查浏览器设置
4. 检查控制台错误

**快速解决**：
- 启用WebGL
- 更新显卡驱动
- 调整浏览器设置
- 重新加载资源

### 问题3：交互无响应

**可能原因**：
- JavaScript错误
- 事件监听失效
- 控制逻辑错误
- 性能问题

**快速检查**：
1. 检查控制台错误
2. 测试其他交互
3. 检查事件监听
4. 检查性能状态

**快速解决**：
- 修复JavaScript错误
- 重新绑定事件
- 优化控制逻辑
- 优化性能

### 问题4：动画卡顿

**可能原因**：
- 帧率过低
- 渲染负载过高
- 资源占用过高
- 性能优化不足

**快速检查**：
1. 检查帧率
2. 检查渲染负载
3. 检查资源占用
4. 检查性能优化

**快速解决**：
- 降低渲染负载
- 优化资源占用
- 减少粒子效果
- 优化渲染流程

### 问题5：视觉效果差

**可能原因**：
- 光照设置不当
- 材质参数错误
- 后处理缺失
- 渲染设置不当

**快速检查**：
1. 检查光照设置
2. 检查材质参数
3. 检查后处理效果
4. 检查渲染设置

**快速解决**：
- 调整光照设置
- 修正材质参数
- 添加后处理效果
- 优化渲染设置

## 评估维度快速参考

### 提示词匹配度

**快速检查**：
- 列出用户需求中的所有要求
- 逐一检查产物中的对应实现
- 记录缺失或不完整的元素

**常见问题**：
- 元素/特效缺失
- 风格偏离
- 完整性不足

**快速评估**：
- 优：完全满足需求
- 良：基本满足需求
- 中：部分满足需求
- 差：严重不满足需求

### 功能与交互

**快速检查**：
- 测试所有交互方式
- 检查响应速度和准确性
- 观察动画流畅度

**常见问题**：
- 镜头逻辑问题
- 动画/状态机问题
- 交互触发问题

**快速评估**：
- 优：功能完整，交互流畅
- 良：功能基本完整，交互有轻微问题
- 中：功能部分完整，交互有明显问题
- 差：功能严重缺失，交互体验差

### 产物技术质量

**快速检查**：
- 检查模型是否有穿模、破面
- 检查材质和渲染是否正常
- 检查性能是否达标

**常见问题**：
- 模型/物理硬伤
- 材质/渲染Bug
- 性能与健壮性问题

**快速评估**：
- 优：技术实现精良，无技术问题
- 良：技术实现良好，有轻微问题
- 中：技术实现一般，有明显问题
- 差：技术实现差，有严重问题

### 美学与体验

**快速检查**：
- 评估光影效果
- 评估色彩搭配
- 评估整体布局

**常见问题**：
- 光影/渲染层次问题
- 色彩/后处理问题
- 布局问题

**快速评估**：
- 优：视觉效果精美，体验优秀
- 良：视觉效果良好，体验良好
- 中：视觉效果一般，体验一般
- 差：视觉效果差，体验差

## 时间管理建议

### 时间分配

| 任务 | 建议时间 | 优先级 |
------|----------|--------|
| 快速检查 | 1-5分钟 | 高 |
| 深度体验 | 15-20分钟 | 高 |
| 维度评估 | 20-30分钟 | 最高 |
| 问题定位 | 10-15分钟 | 高 |
| 备注填写 | 10-15分钟 | 高 |
| 核对保存 | 5分钟 | 中 |

### 时间优化技巧

1. **并行处理**：在体验过程中同时记录问题
2. **优先级排序**：先处理核心问题，再处理次要问题
3. **模板使用**：使用备注模板提高填写效率
4. **快捷键使用**：使用快捷键提高操作效率

## 常见错误快速识别

### 错误1：需求匹配度评估不准确

**快速识别**：
- 备注中没有具体说明哪些需求被满足
- 备注中没有具体说明哪些地方有偏差
- 备注中没有提供证据支持

**快速纠正**：
- 列出用户需求中的所有要求
- 逐一检查产物中的对应实现
- 提供具体的问题描述和证据

### 错误2：功能与交互评估不具体

**快速识别**：
- 备注中没有具体说明哪些功能正常
- 备注中没有具体说明问题的具体表现
- 备注中没有提供证据支持

**快速纠正**：
- 测试所有功能，记录表现
- 具体说明问题的具体表现
- 提供具体的问题描述和证据

### 错误3：技术质量评估不深入

**快速识别**：
- 备注中没有具体说明技术实现细节
- 备注中没有具体说明检查了哪些方面
- 备注中没有提供证据支持

**快速纠正**：
- 检查技术实现细节
- 具体说明检查了哪些方面
- 提供具体的问题描述和证据

### 错误4：美学与体验评估主观

**快速识别**：
- 备注过于主观，没有客观标准
- 备注中没有具体说明美观在哪里
- 备注中没有提供证据支持

**快速纠正**：
- 设定客观评估标准
- 具体说明美观在哪里
- 提供具体的问题描述和证据

### 错误5：备注笼统模糊

**快速识别**：
- 备注过于笼统，没有具体信息
- 备注中没有说明哪里不错
- 备注中没有说明优化什么

**快速纠正**：
- 提供具体的问题描述
- 说明哪里不错，哪里需要优化
- 提供具体的问题描述和证据
