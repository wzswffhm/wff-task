完成。`treefiles` 之前只在配置解析里存在(`F_TREEFILES` 标志位被读进来就再没人用),`treefiles.c` 是一句 "not implemented" 的注释。现在按 man 文档(`nbd-server.5`)描述的行为补齐了,实现参照上游 nbd 的同名功能。

## 改动

**`treefiles.c`(新实现,此前是空壳)** — 四个树结构辅助函数:
- `construct_path`:把导出内偏移递归映射成 `导出名/TREEXXXX/.../FILEXXXX` 路径;树深度由 filesize 决定,每层最多 1024 项,叶子文件固定 4096 字节
- `open_treefile`:按需打开块文件;不存在时(读写模式)自动建目录并创建、扩展到 4KB;(只读模式)用匿名临时文件补零返回
- `mkdir_path` / `delete_treefile`:建路径 / 删块文件

**`nbd-server.c`**
- `get_filepos`:treefiles 时不再查 export 数组,而是算出块内偏移、按需 `open_treefile`,单次 I/O 限制在单个块文件内
- `rawexpread` / `rawexpwrite` / `rawexpsplice`:用完即关块文件 fd(跨块请求由 `_fully` 循环逐块进行)
- `expflush`:treefiles 时不能遍历空数组,改为 `sync()`
- `setupexport`:treefiles 导出不再打开单一文件(`export=NULL`、大小取 filesize),并校验 man 文档要求的 filesize 必填;treefiles 与 multifile 同时给出时 treefiles 优先

**`nbdsrv.c`** — `exptrim`:treefiles 时把 TRIM 范围里被完整覆盖的块文件直接删除(半块不删),此后读回为全零。
