## 实现内容(按 man 页 nbd-server(5) 描述的行为)

**`treefiles.c`(核心实现)**
- 导出按 4096 字节块(TREEPAGESIZE)切分,每个目录最多 1024 个条目(TREEDIRSIZE);块号按 1024 进制展开成路径:`exportname/TREEXXXX/.../FILEXXXX`,嵌套层数按 `filesize` 自动取最少层级(≤1024 块时块文件直接放在根目录)
- `construct_path` / `mkdir_path` / `open_treefile` / `delete_treefile`:按头文件既有契约实现,块文件按需创建(含目录 `mkdir -p`),用传入的 mutex 串行化创建
- `tree_read`:跨块读;块文件不存在读作全零(稀疏语义),尾块不足 4096 的部分补零
- `tree_write`:跨块写、按需建文件,尊重 F_SYNC/FUA;整块写零会删除对应块文件(即"块标记为未使用")
- `tree_trim`:TRIM 范围内整块覆盖的块文件直接删除

**`nbd-server.c` / `nbdsrv.c` / `nbdsrv.h`(接线)**
- `setupexport`:treefiles 导出不在连接时打开任何文件,`exportsize` 取自 `filesize`,块文件随读写按需打开;man 页规定 treefiles 优先于 multifile,已实现
- `rawexpread`/`rawexpwrite` 开头拦截 F_TREEFILES 走树读写;`exptrim`、`expflush` 加了树模式分支,避免解引用空导出数组
- CLIENT 增加 `tree_lock`(请求经线程池并发处理,保护块文件创建/删除)
- 配置校验:treefiles 必须配 `filesize`,否则启动即报错;与 `waitfile`、`splice` 混用报错
