## 改动内容

**`nbdsrv.h`** — `CLIENT` 结构新增 4 个 COW 状态字段:
- `difffile`:diff 文件描述符(-1 表示未启用)
- `diffname`:diff 文件路径(断开时删除)
- `diffpages`:哈希表,记录本连接写过的页 → 该页在 diff 文件中的偏移
- `diffend`:非 sparse 模式下页追加到 diff 文件末尾的位置

**`nbd-server.c`** — 把原来的 `rawexpread`/`rawexpwrite` 拆成读写主文件的 `master_expread`/`master_expwrite`,在其上加分发层,并新增:
- `setup_cowfile()`:在 `commit_client()` 里、`setupexport()` 之后调用。按 `cowdir`(缺省则主文件同目录)创建 `<name>-<pid>.diff`;`sparse_cow` 时把 diff 文件 `ftruncate` 到导出大小。
- `cow_write()`:写入只进 diff 文件、不动主文件,并在 `diffpages` 登记。页首次被部分写入时,先从主文件拷回整页再叠加新数据,保证 diff 里的页是完整的;`F_SPARSE` 下页按真实偏移存放,否则追加到文件末尾。
- `cow_read()`:按 `DIFFPAGESIZE` 判断,命中 diff 的页优先从 diff 读,其余读主文件,并尽量合并同状态的连续页。
- `cleanup_cowfile()`:挂进 `finalize_client()`,断开(含正常 DISC、掉线)时关闭并 `unlink` diff 文件、释放哈希表。
- `expflush()` 一并 `fsync` diff 文件。

并发上用已有的 `export_lock` 读写锁保护(diff 状态读用 rdlock、写用 wrlock),兼容默认 4 线程池。
