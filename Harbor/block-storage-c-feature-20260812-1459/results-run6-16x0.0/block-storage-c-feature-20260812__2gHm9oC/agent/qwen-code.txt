## 改动内容

**`nbdsrv.h`** — 恢复 CLIENT 结构中被剥掉的 4 个 COW 字段(与 `tests/code/trim.c` 引用的名字一致):`difffilename`、`difffile`、`difffilelen`、`difmap`。

**`nbd-server.c`** — 在 `get_filepos()` 之后新增写时复制层:

- **diff 文件管理**:`difffile_setup()` 在连接建立(`setupexport`)时为 COW 导出创建 `<cowdir 或主文件目录>/<文件名>-<pid>.diff`;`difffile_cleanup()` 关闭并 unlink 它。清理挂在 `finalize_client()`(线程池排空之后,保证无 in-flight 请求)和 `negotiate()` 的失败路径(GO 之后又 abort 的场景)。
- **写路径**:`rawexpwrite` 对 `F_COPYONWRITE` 分发到 `difffile_write`。按 4096 字节页处理:页已在 diff 中 → 原位覆盖;不在 → 先从主文件读回该页、合并新数据、整页写入 diff(部分页写因此不会损坏页内其余数据),并在位图中登记。原主文件路径抽为 `masterwrite`。
- **读路径**:`rawexpread` 分发到 `difffile_read`,逐页查位图:已写页优先从 diff 读(两种布局分别换算偏移),未写页回落 `masterread`。
- **两种布局,照 man 页语义**:默认布局把新写页追加到 diff 文件末尾(页在文件中的位置 = 位图中它之前已置位的页数);`sparse_cow`(F_SPARSE)则把 diff 预扩到导出大小,页按原偏移存放。
- **并发**:读写分别取已初始化但一直闲置的 `client->export_lock` 读/写锁(请求由线程池多线程处理,保护位图和追加位置)。
- **其他**:`expflush` 同时 fsync diff 文件;`commit_client` 初始化 `difffile = -1`;TRIM 对 COW 维持现有的"暂不支持"早退逻辑不变。
