## 实现内容

**`nbdsrv.h`** — `CLIENT` 增加每连接的 COW 状态(字段名与 `tests/code/trim.c` 的期望一致):`difffilename`、`difffile`、`difffilelen`、`difmap`(块→diff 偏移映射,4 KiB 一块),以及保护它们的 `difflock`。

**`nbd-server.c`**:

1. **主文件只读**:`setupexport()` 对 COW 导出以 `O_RDONLY` 打开主文件(仅在需创建文件时用 `O_RDWR|O_CREAT`),并绕过 O_RDWR→只读 的回退逻辑,保证主文件只读介质上写入也能被接受(写入全部走 diff)。
2. **连接建立**:`commit_client()` 初始化 `difflock`,在导出大小确定后调用 `setup_cow()` 创建 diff 文件——名字带 pid 避免并发连接冲突(`<导出名>.<pid>.diff`,或按 `cowdir` 语义放到指定目录);`sparse_cow` 时把 diff 预扩到导出大小,块按原偏移存放;否则块首次写入时追加到 diff 末尾。
3. **写路径**:`expwrite()` 对 COW 改走 `expcowwrite()`,按 4 KiB 块写入 diff;块首次变脏时先从主文件复制该块原内容(copy-on-write),保证块内未被覆盖的部分仍读得到主文件数据(测试中非对齐部分写依赖这一点)。`F_SYNC`/FUA 语义同步到 diff 文件。
4. **读路径**:`expread()` 对 COW 改走 `expcowread()`,逐块查 `difmap`:命中则从 diff 读,未命中回落主文件;兼容 structured reply 的分块回包。
5. **FLUSH**:COW 时只 fsync diff(主文件只读)。TRIM 维持现状(代码中原有注释即注明 COW 上暂未实现,返回成功)。
6. **断开清理**:`finalize_client()` 在线程池销毁(确保无在途请求)后调用 `cleanup_cow()`:关闭并 `unlink` diff 文件、释放映射。`NBD_CMD_DISC` 和连接异常断开两条路径都经过这里。
