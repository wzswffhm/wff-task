## 改动内容

**`treefiles.c`(原为 stub,现完整实现)**,用 `treefiles.h` 里已声明的接口:
- `construct_path()`:把导出内偏移映射成路径。块大小固定 4096(`TREEPAGESIZE`),每层目录最多 1024 个条目(`TREEDIRSIZE`),按 filesize 算出需要的嵌套层数,块号按 1024 进制展开成 `exportname/TREEXXXX/.../FILEXXXX`(≤4MB 只有一层 `FILEXXXX`,更大则逐级 `TREEXXXX` 目录)
- `mkdir_path()`:递归建目录;**`open_treefile()`**:按需打开/创建块文件(建目录用传入的 mutex 串行化,照顾 man 里提到的 fuse/davfs 这类网络文件系统);**`delete_treefile()`**:删除块文件

**`nbd-server.c`**:
- `setupexport()`:treefiles 导出不预先开文件(可能上千个),`client->export = NULL`、大小取 `filesize`(未指定则拒绝连接,对应 man 里 "filesize 必须指定");文件句柄在读写时按需开关
- 新增 `rawexptreefile_read/write` + `expread_treefile/expwrite_treefile`,并在 `expread`/`expwrite` 开头按 `F_TREEFILES` 分派(放在 COW/普通路径之前,兼容 structured replies)
- 没写过的块读回来是零;写时自动建目录建文件;`F_SYNC`/FUA 语义与普通导出一致
- `parse_cfile()` 拒绝 treefiles 与 copyonwrite/splice/waitfile 混用(会崩的组合),multifile 混用时按 man 文档由 treefiles 优先

**`nbdsrv.c`/`nbdsrv.h`**:`exptrim()` 对 treefiles 导出把完全被 TRIM 覆盖的块的块文件删掉(man:"块被标记 unused 时文件删除",之后读回零);新增配套错误码。不配 treefiles 的导出走的代码路径完全没动。
