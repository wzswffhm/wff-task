# 质检分数要求（写入 harbor-skill 标准）

来源：质检文档 **4.2 关键指标**、**5.2 分数解读**。交付前对照自检。

## 4.2 关键指标（难度 / Trial 侧）

| 指标 | 含义 | 理想范围 |
|------|------|----------|
| **平均通过率** | 所有 **有效** Trial 的平均 reward | **0.3 – 0.7** |
| **任务难度分布** | 各任务通过率的分布 | **正态分布**（勿扎堆全 0 或全 1） |
| **评分一致性** | 同任务多次运行的方差 | **低方差** |
| **Agent 区分度** | 不同 Agent 的表现差异 | **有显著差异** |

执行要点：

- 只统计有效终态（正常跑完且写出 reward）；**超时/cancel 导致的 0 分不计入**，且整 job 作废重跑。
- 单题 16 trial、reward 近似 0/1 时：均值 ∈ [0.3, 0.7] ≈ **满分约 5–11 次**。
- 均值 **> 0.7**（过易）→ 加难 / 换大型工程，不可交付。
- 均值 **< 0.3**（过难或超时污染）→ 先排除超时；仍过低则降难或换切点，不可靠「全 0」装难。
- 甲方/本标注流难度门硬规则（优先）：有效 `reward=1` 必须在 **1–3 / 16**；**=0 过难换题**；**≥4 立刻杀 job 改题**。  
- 文档 4.2「平均通过率 0.3–0.7」作数据集层面参考；**与满分 1–3 冲突时，以满分 1–3 与换题规则为准**（本标注流）。

## 5.2 分数解读（质检综合分 / 任务质量分）

| 分数范围 | 含义 | 建议 |
|----------|------|------|
| **0.9 – 1.0** | 优秀 | 可以直接使用 |
| **0.7 – 0.89** | 良好 | 根据建议微调 |
| **0.5 – 0.69** | 一般 | 需要改进 |
| **0.3 – 0.49** | 较差 | 需要重大修改 |
| **0.0 – 0.29** | 严重问题 | 建议重写 |

交付目标：质检综合分力争 **≥ 0.7（良好及以上）**；落入 **≤ 0.49** 必须大改或重做，**≤ 0.29 按重写**（换仓/重出题），不要小修糊弄。

## 与 P0 / 难度门的关系

1. P0（baseline+oracle 跑通且进 zip + 真实 rubrics/rewardkit；**smoke 可选**）不过 → 直接不通过，无论分数带。对照 `zq2026080704332` 质检挂单。  
2. 难度 job 须满足关键指标平均通过率 **0.3–0.7**（有效样本）。  
3. 超时刷 0 → 作废重跑（见 pitfalls）。  
4. 飞书回写与 zip 仅在上述都满足后执行。
