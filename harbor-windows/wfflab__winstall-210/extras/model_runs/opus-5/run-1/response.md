修复了 winstall 在 Windows 上的三类故障：

1. **版本比较修复**（versions.py）：
   - 将版本号按十进制整数数值比较，而非字符串比较
   - 支持四段版本号（major.minor.build.revision），不足四段补 0
   - 预发布版本（如 1.0.0-beta）低于同号正式版
   - 现在 1.10.0 正确判定为大于 1.9.0

2. **文件占用处理**（transaction.py）：
   - Windows 上文件被占用时不再抛异常，而是加入 deferred 列表
   - 被占用的文件保持旧内容不变
   - 清单版本号立即更新，pending_replace 记录待重试文件
   - 占用解除后再次执行同一计划即可完成替换
   - 自动清理所有 .winstall-part 临时文件

3. **失败回滚机制**（transaction.py）：
   - 遇到不可延迟的错误（如目标是同名目录）时触发完整回滚
   - 从备份恢复所有已覆盖的文件
   - 删除所有本次新建的文件
   - 清单恢复到执行前状态
   - 清理所有临时文件和备份文件

所有可见回归测试通过，公开 API 签名保持不变，仅使用 Python 标准库。
