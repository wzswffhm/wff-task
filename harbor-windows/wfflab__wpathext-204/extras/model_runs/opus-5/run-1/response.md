修复了 wexec 在 Windows 上查找和执行非 .exe 命令的三个核心问题：

1. **PATHEXT 支持**：`executable_extensions()` 现在读取并解析 `PATHEXT` 环境变量，返回小写标准化的扩展名元组，缺失时退回 `(".exe",)` 兜底值。

2. **扩展名叠加修复**：`resolve()` 现在检测命令名是否已带扩展名。如果已有（如 `tool.exe`），直接查找该文件而不再追加扩展名；如果没有（如 `tool`），按 PATHEXT 顺序试探所有扩展名。

3. **批处理脚本执行**：`run()` 检测 `.bat` 和 `.cmd` 文件，通过 `cmd.exe /c` 启动，确保脚本可执行且退出码正确传递；.exe 等其他可执行文件继续直接启动。

所有修改仅涉及 `wexec/resolve.py` 和 `wexec/runner.py`，未引入新依赖，既有测试全部通过，验证场景包括：
- 不带扩展名查找 .cmd/.bat 文件
- 带扩展名直接命中不叠加
- PATHEXT 顺序决定查找优先级
- 批处理脚本退出码与多行输出正确采集
- 参数正确传递给脚本
