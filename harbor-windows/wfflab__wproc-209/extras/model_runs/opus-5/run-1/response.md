修复了 wproc 在 Windows 上的三个核心问题：

1. **进程树终止**：使用 Windows Job Object 管理进程树，超时时终止所有后代进程（包括孙进程）。实现了智能降级策略以处理已在 Job 中的情况。

2. **输出保留**：用独立线程持续读取 stdout/stderr，确保超时时已产生的输出不丢失。支持数百 KiB 的大输出。

3. **快速返回**：轮询检测直接子进程退出，立即返回而不等待后代关闭继承的管道句柄。避免误报超时。

关键实现：
- 在 `wproc/processes.py` 中新增 `_WindowsJobManager` 类，封装 Job Object 的创建、配置和清理
- 修改 `wproc/runner.py` 的 `run()` 函数，用线程读取输出 + 轮询检测退出，替代 `communicate()`
- 保持公开 API 不变，所有现有测试通过

验证结果：
- 超时后后代进程完全停止（ping.exe 不再运行）
- 超时时捕获 33KB 输出（问题 2 前为 0）
- 子进程退出后 0.4 秒返回（问题 3 前需等待 30 秒超时）
- 所有原有测试通过，异常正确携带结果
