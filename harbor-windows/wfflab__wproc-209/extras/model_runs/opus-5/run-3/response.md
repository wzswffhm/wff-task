修复 wproc 在 Windows 上的三个关键问题：

1. **进程树终止**：在 `processes.py` 中使用 CREATE_NEW_PROCESS_GROUP 创建进程组，并在超时时使用 `taskkill /F /T` 终止整个进程树，而不仅是直接子进程。

2. **输出收集**：在 `runner.py` 中实现 Windows 专用逻辑，使用后台线程异步读取输出，确保超时时已读取的输出不会丢失（之前返回空字节）。修复了 POSIX 平台上从 TimeoutExpired 异常中提取输出的问题。

3. **立即返回**：通过轮询直接子进程状态，一旦它退出就立即返回，不再等待后代进程关闭管道句柄。同时设置 close_fds=True 防止后代进程继承管道。

所有既有测试通过，三个关键场景验证成功：进程树被终止、大输出在超时时完整收集、子进程退出后 0.37 秒内返回（而非等待 30 秒超时）。
