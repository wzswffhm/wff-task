修复了 wsafename 在 Windows 环境下的三个关键缺陷：

1. **保留设备名判定** - 修改 `rules.py` 中的 `is_reserved()` 函数，按 Win32 规则只检查第一个点之前的 base name。现在 `CON.txt`、`lpt1.tar.gz` 会被正确识别为保留名并拒绝，而 `console.txt`、`com10.log` 等包含保留字片段但 base name 不保留的名称可以正常使用。

2. **尾部点与空格处理** - 修改 `sanitize.py`，在净化阶段就去除 Windows 会静默丢弃的尾部点和空格（包括截断后可能产生的尾部字符）。这确保了 `report.` 和 `report` 得到相同的落盘名，避免清单与实际内容不一致。

3. **空名称拒绝** - 增强了 `sanitize()` 的验证逻辑，在去除尾部字符后检查名称是否为空。现在 `...`、`   ` 等输入会在净化阶段明确抛出 `InvalidNameError`，而不是等到写盘时才失败。

所有既有测试保持通过，修改仅涉及实现代码，未触碰测试文件。
