## 5. 将历史修复转成通用检查的原则

每条经验至少形成：一个静态风险定位、一个动态正对照、一个失败或等价控制、一个结果字段。平台故障交平台/环境负责人，不通过删 testcase 绕过。语义修复须以公开契约或真实依赖为依据，不以某模型通过率为依据。

不直接照抄历史修复代码：同一题不同版本的 base、镜像、测试、rubric 和题意可能已变。先确认问题在当前版本是否存在，再决定修复与复验范围。
