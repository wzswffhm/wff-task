# 法律领域知识体系、三级标签库与场景矩阵

## 1. 二级标签（规范原文，取值必须逐字一致）

| 二级标签 | 覆盖范围 |
|---|---|
| `Law1-诉讼律师` | 民商事/刑事/行政案件的诉讼代理与辩护：证据组织、起诉状/答辩状、庭审准备、上诉、执行 |
| `Law2-非诉律师` | 交易与合规文书：合同审查与起草、法律意见书、尽职调查、并购与融资文件、公司治理 |
| `Law3-企业法务与合规` | 企业内部法律事务：合规审查、内控与制度、劳动人事、合同管理、知识产权、监管应对 |
| `Law4-法官与法院辅助` | 审判视角：裁判文书说理、争议焦点归纳、类案检索、证据认定、审判辅助事务 |
| `Law5-检察官与检察辅助` | 检察视角：审查报告、证据审查、起诉书、量刑建议、法律监督 |
| `Law6-立法与政策研究` | 规则制定视角：法规起草、条文设计与对照、政策研究报告、征求意见稿 |

## 2. 三级标签示例库（本批须自补；同一三级标签 ≤2 道）

> 下表为**示例**，可按实际场景扩展自定三级标签；关键是粒度落到"具体业务动作"。

| 二级 | 三级标签示例 |
|---|---|
| Law1 | 买卖合同纠纷起诉状起草；违约金调减抗辩论证；证据目录与举证质证意见编制；管辖权异议分析；上诉理由书撰写；执行异议申请 |
| Law2 | 股权转让协议审查；增资协议条款修订；对赌/回购条款分析；法律尽调问题清单编制；交易结构合规性意见；数据合规条款设计 |
| Law3 | 员工违纪解除合规审查；竞业限制协议审查；商业秘密保护制度设计；监管问询回复准备；内部合规事件调查报告；合同模板体系梳理 |
| Law4 | 争议焦点归纳表编制；裁判文书说理段落补写；类案检索报告；证据采信分析；程序性事项裁定要点整理 |
| Law5 | 审查报告撰写；证据合法性审查意见；起诉书制作；量刑建议论证；侦查活动监督意见 |
| Law6 | 地方性法规草案条文设计；条文新旧对照表编制；立法必要性论证；政策研究报告撰写；征求意见稿修改说明 |

## 3. 真实场景与交付物矩阵

> **交付物必须是该场景真实会交付的东西**；本题交付什么，源文件就用什么。

| 场景 | 典型交付物 | 必需源文件 |
|---|---|---|
| 合同审查 | 合同修订稿（.docx，带修订痕迹与批注）+ 审查意见表（.xlsx） | 待审合同、双方往来确认邮件、内部风控要求 |
| 法律意见书 | 法律意见书（.docx） | 交易文件、主体资格材料、尽调资料、适用法规摘编 |
| 尽职调查 | 尽调问题清单（.xlsx）+ 风险提示备忘（.docx） | 工商档案、章程、财务报表、合同台账、诉讼记录 |
| 诉讼文书 | 起诉状 / 答辩状 / 代理词（.docx） | 合同、往来记录、付款凭证、证据清单 |
| 争议焦点归纳 | 争议焦点与请求权基础对照表（.xlsx） | 起诉状、答辩状、证据目录、庭审笔录摘要 |
| 合规审查 | 合规风险清单（.xlsx）+ 整改建议（.docx） | 内部制度、业务流程说明、监管规定摘编 |
| 法规起草 | 草案条文（.docx）+ 条文对照表（.xlsx） | 上位法摘编、现行文件、背景调研材料 |
| 数据计算类 | 赔偿/违约金/利息测算表（.xlsx） | 合同金额与期限条款、付款记录、利率约定 |

## 4. 交付物硬约束写法示例（独立成段，不得藏在括号里）

```markdown
## 交付物要求

交付物必须写入 `/app/output/`，不要把产物写到任何其他绝对路径。

| 交付物 | 是否必交 | 说明 |
| --- | --- | --- |
| `LAW1-001_法律意见书.docx` | 必交 | 完整法律意见书，须含事项概述、事实与证据、法律分析、结论与建议四部分 |
| `LAW1-001_金额测算表.xlsx` | 必交 | 赔偿金额分项测算，含单价、数量、合计三列 |

硬约束（必须遵守）：

1. 意见书正文须在 2500–4000 字之间。
2. 引用法律条文时必须写明法律名称、条、款、项；引用已废止条文视为错误。
3. 不得在交付物中出现任何真实姓名、身份证号、手机号。
4. `金额测算表` 的"合计"须等于各项分项之和（误差不超过 ±0.01 元）。
```
