# 领域 / 子领域枚举（选题与 task.toml 必对齐）

飞书「应用领域」「子领域」与 `task.toml` 的 `domain` / `subdomain` **必须逐字落在下表**，禁止自造近义词。

## 计算产品

- Linux 运行时、系统调用与 I/O
- 云服务器与虚拟化
- 容器运行时与 Kubernetes 基础
- Kubernetes 调度与弹性伸缩
- 网络数据面与负载均衡
- Serverless 与弹性容器
- 异构计算、HPC 与 AI 批任务
- 可观测性、稳定性与成本治理

## 存储

- Linux I/O 与存储介质

- 文件存储
- 对象存储

- 数据保护与存储安全
- 云原生存储
- 性能、运维与前沿演进
- Linux I/O 与本地存储栈
- 单机与嵌入式存储引擎
- 块存储与存储虚拟化
- 存储网络与硬件卸载
- AI 存储与新介质
- 性能工程与运维演进

## 数据库

- 关系型数据库（OLTP）

## 执行要求

1. 选题前先看飞书行已填的领域/子领域；空着则从本表选且与仓库真实方向一致。  
2. `task.toml`：

```toml
[metadata]
domain = "存储"          # 三选一：计算产品 | 存储 | 数据库
subdomain = "块存储"     # 必须是上表原文
```

3. 回写飞书时四列（任务类型/应用领域/子领域/编程语言）与 toml 一致，保证「task.toml 是否正确」✅。  
4. 同项目多题可换子切点，但领域/子领域仍须表内合法值。
