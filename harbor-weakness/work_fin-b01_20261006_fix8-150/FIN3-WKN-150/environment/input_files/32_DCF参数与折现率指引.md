# DCF 参数与折现率指引

> 本指引由投资决策委员会核准，收益法测算须严格按本指引参数执行；
> 参数以外的假设不得自行引入。

## 一、预测期与基准日

1. 估值基准日：**2025 年 12 月 31 日**；
2. 明确预测期：**2026 年至 2030 年，共 5 个完整会计年度**；
3. 2030 年之后为永续期。

## 二、经营假设

| 项目 | 假设 |
|---|---|
| 2026 年营业收入增速 | +10.0%（以 2025 年经审计营业收入为基数） |
| 2027—2030 年营业收入增速 | 每年 +10.0% |
| 预测期毛利率 | 25.0%（各年相同） |
| 预测期销售费用率+管理费用率+研发费用率合计 | 13.5%（各年相同） |
| 折旧与摊销占营业收入比例 | 5.0%（各年相同） |
| 资本性支出占营业收入比例 | 6.0%（各年相同） |
| 营运资本追加 | 按当年营业收入增量×20.0% |
| 所得税税率 | 15.0%（高新技术企业，各年相同） |

> 自由现金流口径：FCFF = EBIT×(1−税率) + 折旧与摊销 − 资本性支出 − 营运资本追加；
> 其中 EBIT = 营业收入 ×(毛利率 − 期间费用率合计)，即营业收入 × 11.5%。
> 永续期不再单独假设资本性支出与折旧。

## 三、折现率参数

| 参数 | 取值 | 说明 |
|---|---|---|
| 无风险利率 Rf | 2.35% | 10 年期国债到期收益率近一年均值 |
| 市场风险溢价 ERP | 6.00% | 委员会核定，**不得另加规模溢价或其他调整** |
| 可比公司 Unlevered Beta 中位数 βu | 0.95 | 取自筛选后可比公司样本 |
| 目标资本结构 D/(D+E) | 20.0% | 即 D/E = 25.0% |
| 债务成本 Kd（税前） | 4.50% | 参考公司现有借款加权平均成本 |
| 所得税税率 t | 15.0% | 同经营假设 |

杠杆化公式：**βL = βu × [1 + (1 − t) × D/E]**
股权成本：**Ke = Rf + βL × ERP**
加权平均资本成本：**WACC = Ke × E/(D+E) + Kd × (1 − t) × D/(D+E)**

## 四、终值

永续增长率 g = **2.5%**。
终值 TV = FCFF₂₀₃₀ ×(1 + g) ÷ (WACC − g)。

## 五、企业价值到股权价值

1. EV = Σ[FCFF_t ÷ (1 + WACC)^t] + TV ÷ (1 + WACC)^5（t = 1…5 对应 2026—2030 年）；
2. **净负债 = 有息负债合计 − 可自由支配的货币资金**（须扣除使用受限的货币资金）；
3. 股权价值 = EV − 净负债；
4. 每股价值 = 股权价值 ÷ 总股本（12,000 万股）。
