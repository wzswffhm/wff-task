### 附：为何不采用"改材料锁死口径"（本轮实测证据）

在甲方定口径之前，本机按 fix2 复审「路径②」做过一次**实测对照**（包内不交付，仅留证据）：把附件4 口径说明改为「12.00% 系按 C 轮融资完成后、期权池设立前计算，仅需扣除期权池 10.00%，完全稀释＝10.80%」，并同步修正金标与附件3 旁注，随后用 **claude-code 框架实跑 qwen3.8-max-0902**（同一判据、同一判官）：

- qwen 实测 **0.942953**（51 条判据），全链数值 `10.80% / 3.78 / 14.70 / 15.00 / 13.60 / 12.81` 全部命中，`9.09% / 3.18` 零命中；
- 唯一两处失分是 R12（判据要求 `4.55＋13.38＝17.92` 这个数学上不成立的等式，模型用精确中间值）与 R20（GP 追赶目标按协议字面解出 1.70 亿元 vs 参考答案 3.40 亿元）——**都不是能力问题，而是新的口径歧义**；
- 结论与 fix2 复审的静态回算一致：口径唯一化后三模型均值将升至约 0.9x，**A2 不再成立**。

因此甲方选定路径①（保留原口径 + 书面确认），材料与判据保持提交版原样，避免"改一处口径、垮掉整档难度"。
