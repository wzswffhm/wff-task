# 附件1　有限合伙协议关键条款摘录

| 条款 | 内容 |
| --- | --- |
| 基金名称 | 鼎元三期股权投资合伙企业（有限合伙） |
| 普通合伙人 / 管理人 | 鼎元资本管理有限公司（GP） |
| 有限合伙人 | 12 名机构及个人有限合伙人（LP） |
| 认缴出资 | 合计 10.00 亿元，其中 LP 9.00 亿元、GP 1.00 亿元 |
| 实缴安排 | 2023-01-01 缴付 5.00 亿元（LP 4.50、GP 0.50）；2024-01-01 缴付 5.00 亿元（LP 4.50、GP 0.50）；已全部缴足 |
| 存续期 | 7 年，2023-01-01 至 2029-12-31；投资期 4 年、退出期 3 年 |
| 管理费 | 存续期内按实缴出资额 1.20%/年 计提，按年支付 |
| 门槛收益 | 8.00% 单利/年，按每笔实缴出资额及其缴付日起算；计息以整年计，不足一年不计息 |
| 分配顺序 | （1）返还各合伙人实缴出资；（2）支付优先回报；（3）GP 100% 追赶，直至 GP 累计分配额占"（1）+（2）+（3）"的 20.00%；（4）剩余部分按 LP 80.00%、GP 20.00% 分配 |
| 业绩报酬 | 按基金累计可分配金额（含已实现与未实现公允价值）于每个估值日模拟计算，计提为应付业绩报酬 |
| 估值日与报告 | 估值日为每年 12 月 31 日；年度报告应于次年 1 月 31 日前提供予全体 LP |
| 回拨机制 | 后续年度公允价值回撤导致已计提业绩报酬超过应计提金额的，差额冲回应付业绩报酬 |

说明：截至 2027-12-31 基金尚未对外分配，全部分配按上述顺序模拟；管理费按已计提金额全额扣减，未付部分作为应付项目。
