# 附件2　基金估值政策与估值指引适用摘要

方法适用顺序：

| 情形 | 适用方法 | 关键参数 |
| --- | --- | --- |
| 已上市或存在活跃市场报价 | 市价法 | 按估值日收盘价；存在限售安排的，另按基金约定的限售折扣 20.00% 计量 |
| 最近一轮融资距估值日不超过 12 个月 | 最近融资价格法 | 直接采用最近一轮融资价格；持股比例须采用完全稀释口径 |
| 最近一轮融资距估值日超过 12 个月 | 可比公司法或现金流量折现法 | 不得直接沿用旧融资价格 |
| 可比公司数据充分 | 可比公司法 | 以可比公司 EV/EBITDA 中位数计算企业价值，扣除净债务得股权价值；对非控制、缺乏流动性的股权另施加 15.00% 流动性折扣 |
| 可预测现金流稳定 | 现金流量折现法 | WACC 10.00%；永续增长率 3.00%；现金流按年末口径折现 |
| 触发清算或回购事件且回购义务人未履约 | 清算价值法 | 按清算情景可分配金额与基金优先清算额孰低值计量 |

通用规则与禁用做法：持股比例一律采用完全稀释口径，登记比例未考虑期权池或后续融资稀释的须换算；可比公司倍数取中位数而非算术平均值；公允价值低于投资成本的差额计入当期减值；未上市股权的流动性折扣与上市限售股的限售折扣按基金约定执行，不得自行调整。不得以投资成本或上一次估值替代本轮估值，不得对已触发清算事件的项目继续沿用历史融资价格，不得对非上市股权与上市限售股适用同一折扣比例。
