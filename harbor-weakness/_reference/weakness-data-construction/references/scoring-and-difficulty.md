# 计分、难度分档与配平

## 一、计分口径（平台 finalize.py 固定实现）

```text
S_max   = Σ 正分条目 weight            ← 负分条目不进分母
分子     = Σ 正分 weight×value − Σ negate weight×(1−value)
主分     = clip(分子 / S_max, 0, 1)
三模型均值 = (score1 + score2 + score3) / 3
```

- `value`：binary 取 0/1；likert 由判官输出 1–5 整数后归一化为 `(raw−1)/4`；
  `negate = true` 的条目由 Reward Kit 自动翻转为 `1 − 归一化值`（完全没违规 = 1）。
- 参考解必须满足全部正分项、且**不得命中任何 negate 条目**。

## 二、难度档与条数下限（两者绑定，必须同时满足）

| 档 | 三模型均值区间 | 法律领域条数下限 | 参考解 | 三模型均值 |
|---|---|---|---|---|
| A1 易 | 0.6 ≤ x < 0.7 | ≥ 25 | > 0.85 | < 0.7（且按档位取更严值） |
| A2 中 | 0.5 ≤ x < 0.6 | ≥ 30 | 同上 | 同上 |
| A3 难 | x < 0.5 | ≥ 35 | 同上 | 同上 |

**难度档不是申报值，而是实测值**：先出题 → 跑分 → 按均值落档 → 回填 `task.toml` 的
`difficulty` / `keywords` / `tags` / `[task].keywords`。条数下限跟着档位走，所以
"想定 A3" 就必须写够 35 条，否则落到 A3 区间也不合规。

## 三、权重分布要求

- 只能取 `{10, 7, 3, -3, -7, -10}`；至少 2 条 `+10`；内容质量维度正分 ≥ 全部正分的 30%。
- **不要以 `+3` 堆叠**：行业性/写作类题目里，"关键结论、指令、规范"= `+10`，
  "重要补充依据、专业规范、论证理由、结构组织"= `+7`，`+3` 只留给细枝末节。
- 常见退回口径：`+10` 占比过高（>60%）会稀释区分度；`+3` 堆成一片会被判"靠 3 分考点降低难度"。
  两种都是权重设计问题，返修时按上面的三档重排。

## 四、改权重/补条前先"零成本回算"

权重或条数一变，分数就变，但**不需要重跑 agent**：已有的逐条判分明细
（`reward-details.json` 里的 `id / value`）就是判官对所有条目的原始判断，可以直接回算新分。

```text
新分子 = Σ_{正分} w'·v − Σ_{negate} w'·(1−v)
新均值 = 新分子_i 的三模型平均 / 新 S_max
```

推论（很常用）：

- 把一条三模型都判 1.0 的 `+3` 提到 `+7`：分子与分母同时 +4，均值被拉向 1.0；
- 把一条三模型都判 0 的条 `+3` 提到 `+7`：分子不变、分母 +4，均值被压低；
- **把负分条从"未违规得分"改回 `negate` 语义时**：三模型与参考解的分数会整体下移
  `Σ|负分权重| / S_max` 的量级，必须重新定档。

先用回算把均值调到目标区间中点（留 ±0.03 的判官波动余量），再跑一次真实判分定档。

⚠ **回算的适用边界**（本轮实例）：回算只在"权重或条数变了、判据语义没变"时准确。一旦动了判据描述本身
（新增要求、删掉某个得分前提、把口径换成另一套），旧 `value` 就不再代表新判据下的表现，回算只能给粗区间。
本轮 LAW-004 回算得 0.6037~0.6766（A1），实测 0.5838（A2）——偏差来自 R06 改成"必须援引规则门槛
并与材料记载数值比对"后，模型在该条上的实际得分低于回算假设。**申报难度档必须以实测为准**，
交付文档里的回算结果要显式标注为"中间估计，最终以重跑为准"。

## 五、阈值之外的常见坑

- **参考解卡在 0.85 边缘**：多半是某条判据写得有歧义，参考解"做了但判官不认"。
  先看 `reward-details.json` 里参考解掉分的条目的 reasoning，区分三种情况并分别处理：
  ① 判据歧义 → 改判据措辞（如把"同步完成"改成"不限定先后"）；
  ② 答案缺内容 → 补参考答案内容（不得放宽判据）；
  ③ 判官漂移 → 保留，但要保证余量足够。
- **判据之间互相矛盾**：例如一条要求"指出内部邮件口径错误"，另一条又要求"不得复述内部讨论内容"。
  这类必须收窄措辞，否则参考解必然掉分。
- **判据要求引用输入材料之外的法规/标准编号**，与题面"只能依据 /app/input_files/"冲突——
  改成同等深度、但可由材料推出的要求。
- **判据措辞要贴合题目领域**：把表格/财务类用语（"可逐格复算的定位（单元格、公式）"）写进
  法律、写作类题目，会被判"表述不贴切"。换成该领域可核验的定位：规则条款编号、协议条款序号、
  材料具体记载位置。出题时按交付物形态统一一套定位语。
- **同一角度不得既写得分点又写失分点**，也不要让两条判据互相矛盾（例：一条要求"指出内部邮件
  口径错误"，另一条又要求"不得复述内部讨论内容"）——参考解会必然掉分。
