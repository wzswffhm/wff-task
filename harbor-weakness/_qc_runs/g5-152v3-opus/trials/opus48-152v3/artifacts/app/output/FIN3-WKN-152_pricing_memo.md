# Pricing Committee 备忘录 — Reddit, Inc. IPO 发行前复核

**项目号** FIN3-WKN-152 **信息截止** 2024-03-20 **估值基准** 2024E Revenue
**控制口径** Committee_Policy_v3_20240320.xlsx（取代 v2：CP-03 SBC、CP-07 peer 区间、CP-09 折扣、CP-12 费基均以 v3 为准）

## 一、最终定价建议：Proceed

拟议价 **$34.00** 落在委员会支持区间 **$31.27–$37.25**（低/中/高档 $31.27 / $34.26 / $37.25）内，距 midpoint 仅 **-$0.26**，未超 CP-14 的 $0.50 阈值；发行结构已无未决 hard error。依 CP-14 建议 **Proceed**。注意 $34 为内部决策输入，非已实现结果，不得与最终定价混用。

## 二、支持价格区间推导

主估值采用 EV / 2024E Revenue（CP-05，承销口径 EBITDA 为负）。2024E Revenue = 804.029 ×(1+22%) = **980.915**（22% 为内部假设，非公开披露）。按 CP-07 peer 区间 4.0x/4.5x/5.0x 得 EV；CP-08 完整净现金桥加回年末 cash 401.176 与 marketable securities 811.946 得 pre-money equity；除以 143.716563m 经济股数后，按 CP-09 统一施加 12.5% 执行折扣，得上述三档每股价值。承销商 A/B 自编 comps（4.0–5.0x / 4.2–5.1x）仅作交叉验证，不改区间端点。

## 三、盈利质量风险（CP-13 披露）

管理层 Adjusted EBITDA -69.275；按 CP-03 将 SBC 及相关税费 49.086 视为持续性成本、剔除加回，得**承销口径 EBITDA -118.361，仍为负**。CP-04 下重组费 8.098 已含于管理层口径，不二次加回。2023A FCF **-84.838 亦为负**。承销口径盈利与现金流双负构成核心 QoE 风险，须向委员会明确披露。

## 四、发行结构与募集

Base 发行 primary 15.276527m、secondary 6.723473m。Secondary 为老股转让，**不形成公司募集资金、不增加公司总股数**。公司 primary gross = 15.276527×$34 = **519.402**；承销费按 primary gross 5% = 25.970（CP-12，不含 secondary）；固定费用 7.0 仅计一次，**net primary = 486.432**。3.3m greenshoe 不并入 Base；full-exercise 下 primary 18.576527m、gross 631.602、net **593.022**（固定费用不重复）。
股本桥：post-money base = 143.716563 + 15.276527 = **158.993090m**，新股占 **9.61%**；full-exercise 162.293090m，占 11.45%。SEC-02 独立口径（假定价 $32.50 下 NTBV $11.17、即时稀释 $21.33）仅用于方向性交叉验算，不作 $34 定价依据。

## 五、数据口径处置（来源优先级）
