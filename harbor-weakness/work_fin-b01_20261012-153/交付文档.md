| 长跑托管 | **不要用 `systemd-run`（缺 `--no-block`）或 `systemctl start` 的 transient/service 方式**：本环境下 wsl.exe 会话结束会使该 unit 收到停止、verifier 被 kill 并写入 fail-closed 占位（`verifier_error=1`）。可行做法是 `setsid nohup bash <脚本> &`（脱离会话），或以 Windows 侧持有的长驻 wsl 会话拉起 |
| 判官/候选并发 | judge 逐条串行 `claude -p`；同一 `JUDGE_API_KEY` 上叠加候选模型 agent 流量会互相拖死 → 候选模型应使用独立 key |
| 已知无害告警 | `Artifact sources overlap: '/logs/artifacts' 与 '/logs/artifacts/output'`（`artifacts` 固定项，149–152 同款） |
| fail-closed 占位 | verifier 运行期间 `verifier/reward.json` 会先写入 `verifier_error=1` 的占位，**finalize.py 成功后由 test.sh 删除**；判定 G4 结果须以最终 `reward.json` 与 `reward-details.json` 为准，不得凭中间态占位下结论 |
| 故障分识别 | `verifier_error = 1` 是「评分不可信」，**不是 0 分**，不得计入难度统计 |
| 端点凭据来源 | 候选模型端点统一取**仓库根 `models.local.json`**（2026-10-12 起为该文件唯一事实来源）；`.gitignore` 以 `!models.local.json` 放行该文件，其余 `*.local.json` 仍忽略；该文件含明文 API Key，**仅限内部仓库，禁止外发** |
