# 税务情况说明

## 一、主要税种及税率

| 税种 | 税率 | 说明 |
|---|---|---|
| 企业所得税 | 15% | 高新技术企业优惠税率（证书有效期 2024—2026 年） |
| 增值税 | 13% | 货物销售 |
| 城市维护建设税 | 7% | 按应纳增值税计缴 |
| 教育费附加 | 3% | 按应纳增值税计缴 |

## 二、税收优惠

公司于 2021 年首次取得高新技术企业证书，2024 年通过复审，优惠期至 2026 年。
若 2027 年未能通过复审，企业所得税税率将恢复至 25%。

## 三、税务合规

报告期内公司不存在重大税务违法违规情形，无欠缴税款。2025 年度收到的政府补助
中，有 300 万元正在接受主管部门条件复核（详见《18_期后事项与未决诉讼.md》）。
