# 企业自报财务数据说明

本表（12_企业自报财务数据汇总.csv）系本公司管理口径财务数据，由公司财务部根据内部管理报表编制，用于反映经营业绩的实际情况。

## 口径说明

1. **营业收入**：本表营业收入包含已发出商品但尚未取得客户验收单据的部分（2025 年度该类发出商品对应收入约 6,000 万元），公司认为相关商品控制权已实质转移，故在管理口径中确认收入。
2. **营业成本**：按与收入配比的原则结转。
3. **净利润**：按管理口径收入与成本计算，未考虑审计调整及资产减值等因素。
4. 本表数据与经审计财务报表存在差异时，请以审计报告为准；本表仅供银行了解公司真实经营情况参考。
