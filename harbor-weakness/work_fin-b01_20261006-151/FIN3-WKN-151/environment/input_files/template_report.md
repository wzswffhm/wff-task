# 授信审批报告（模板）

> 本模板规定报告的章节结构，各章节标题应予以保留并填写实质内容；不得删除章节或保留本模板的填写说明文字。

## 一、授信结论与建议

（填写：是否同意授信、建议授信额度、期限、品种、定价、担保方式、核心结论摘要）

## 二、材料核验与数据口径

（填写：本次收集材料的覆盖情况；材料之间数据口径差异及处理；采用口径说明）

## 三、客户与经营概况

（填写：客户基本情况、股权结构、所属行业、主营业务与经营模式、市场地位）

## 四、财务状况与偿债能力分析

（填写：资产负债结构、盈利能力、营运能力、现金流质量；偿债能力指标测算）

## 五、授信需求测算与额度建议

（填写：营运资金需求测算过程与结果；各项约束测算；孰低原则确定建议额度）

## 六、担保与风险缓释

（填写：拟接受押品、抵押率、合格担保值测算；保证担保安排；风险缓释效果）

## 七、风险分类与授信条件

（填写：五级分类结果与依据；建议的授信条件、财务约束与提款条件）

## 八、风险提示与贷后管理要求

（填写：主要风险点与分级；贷后监控指标与频度；到期管理安排）
