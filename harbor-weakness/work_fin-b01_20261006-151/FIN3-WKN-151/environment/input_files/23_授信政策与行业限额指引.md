# 华信银行授信政策与行业限额指引（2026 年版·节选）

## 一、总体授信政策

1. 本行授信业务应坚持"安全性、流动性、效益性"原则，审慎评估客户信用风险。
2. 单一集团客户授信集中度管理：**单一集团客户授信余额不得超过本行资本净额的 15%**（资本净额数据由计划财务部按季提供，见《资本管理月报》，本指引不列示具体数值）。
3. 制造业客户授信应重点考察其经营性现金流、应收账款质量及抵押担保覆盖情况。

## 二、行业授信限额

| 行业 | 行业政策 | 授信增速上限 |
|---|---|---|
| 通用设备制造业 | 适度支持 | 不超过全行对公贷款增速的 1.5 倍 |
| 房地产 | 审慎 | 严格控制 |
| 批发零售业 | 择优支持 | — |

> 本行对通用设备制造业未单独设定单一客户授信额度上限，按总体授信政策执行。

## 三、担保管理

### 3.1 抵押/质押率标准

| 押品类别 | 最高抵押/质押率 |
|---|---|
| 商业用房及厂房 | 70% |
| 住宅 | 70% |
| 国有土地使用权（工业用地） | 60% |
| 应收账款 | 50% |
| 上市公司股权 | 50% |
| 非上市公司股权 | 40% |
| 存货 | 50% |

> 注：本表未列示**专用设备**（如行业专用生产线、定制化设备、加工中心等）的抵押率。对未在本表列示的押品类别，抵押率应逐笔报总行风险管理部审批后确定，不得由营销或审批人员自行设定。

### 3.2 保证担保

1. 接受自然人或法人提供的连带责任保证。
2. 关联方保证原则上不作为唯一担保方式，应配合抵质押担保。

## 四、授信期限与品种

1. 流动资金贷款期限原则上不超过 1 年。
2. 银行承兑汇票、国内信用证保证金比例原则上不低于 20%，对信用等级 AA- 以上客户可适当下调。
