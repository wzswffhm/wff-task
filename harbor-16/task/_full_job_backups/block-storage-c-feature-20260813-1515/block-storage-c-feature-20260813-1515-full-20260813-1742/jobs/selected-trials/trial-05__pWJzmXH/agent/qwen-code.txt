## 实现的行为(man 页语义)

- 配了 `treefiles = true` 的导出,`exportname` 变成一棵文件树的根目录;数据按 4096 字节块(`TREEPAGESIZE`)拆分存储,每级目录最多 1024 个条目(`TREEDIRSIZE`),嵌套深度由 `filesize` 决定
  - 4 MiB(1024 块)→ 块文件直接放在根目录下:`nbd.tree/0000` … `nbd.tree/1023`
  - 8 MiB(2048 块)→ 多一层:`nbd.tree/0000/0122`、`nbd.tree/0001/0476`
- 块文件按需自动创建(含中间目录);从未写过的块读回是全零;TRIM 整块时删除对应文件,部分覆盖的块只把被 trim 的字节清零
- `filesize` 必填(无法自动探测树的大小),缺了会在客户端连接时报错拒绝
- 与 `multifile` 同时给出时 treefiles 优先(man 页规定);与 `splice`/`waitfile` 互斥,配置解析阶段直接报错
