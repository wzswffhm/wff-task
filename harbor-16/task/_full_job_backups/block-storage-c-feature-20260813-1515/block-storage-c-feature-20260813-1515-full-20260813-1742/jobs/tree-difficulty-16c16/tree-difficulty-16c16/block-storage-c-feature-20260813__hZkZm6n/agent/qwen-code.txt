## 问题根源

`treefiles.c` 原本只有一行注释("not implemented"),配置解析和 man 文档都在,但没有任何实现——配了 `treefiles = true` 的导出直接落回普通单文件路径。

## 实现内容(按 man 文档和 `treefiles.h` 的既定设计)

**数据布局**:`exportname` 成为树的根目录,数据按 4096 字节(`TREEPAGESIZE`)一块拆成 `FILEXXXX` 文件;每个目录最多 1024(`TREEDIRSIZE`)个条目,块数超出时按 1024 进制自动生成 `TREEXXXX` 子目录嵌套。块索引直接映射成路径,不同偏移落在树的不同位置。

**改动文件**:
- `treefiles.c` — 实现 `construct_path` / `mkdir_path` / `open_treefile` / `delete_treefile`,树的深度由 `filesize` 推导
- `nbd-server.c` — 新增 `treeexpread`/`treeexpwrite`(块文件按需打开/创建,未写过的块读回为零),挂进 `rawexpread`/`rawexpwrite`;`setupexport` 增加 treefiles 分支(建根目录、句柄按需打开);`expflush` 分支;`commit_client` 初始化新增的每客户端 `treelock`;配置解析处校验:缺 `filesize` 报错,与 copyonwrite/waitfile/splice/temporary 混用报错,multifile 同时给出时 treefiles 优先(man 文档规定)
- `nbdsrv.h` / `nbdsrv.c` — CLIENT 增加 `treelock`;TRIM 请求对整块覆盖的块删除文件(空子目录一并移除)、部分覆盖的块打洞
- `tests/code/treefiles_test.c` + `Makefile.am` — 新增单测:深度 0/1/2 的路径构造、按需创建/读写/删除、ENOENT 语义、TRIM 删块与打洞
- 顺手恢复了 `tests/run/simple_test` 等脚本丢失的执行位(之前整个 run 测试套件因此全挂)

普通导出路径未动。
