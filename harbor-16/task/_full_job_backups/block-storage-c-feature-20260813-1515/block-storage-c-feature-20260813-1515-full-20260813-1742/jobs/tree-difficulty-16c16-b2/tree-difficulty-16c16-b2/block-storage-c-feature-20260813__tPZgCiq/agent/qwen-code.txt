## 改动

**`treefiles.c`(原为空壳,现为实现)**
- `construct_path`:把导出偏移映射成 `exportname/TREEXXXX/.../FILEXXXX` 路径。数据按 4096 字节块(`TREEPAGESIZE`)切分,每级目录最多 1024 个条目(`TREEDIRSIZE`),按 `filesize` 自动决定嵌套层数
- `open_treefile`:按偏移打开对应块文件;不存在时写模式自动建目录+建文件(并扩到 4096 字节),只读模式用匿名临时文件兜底(读回全零);由互斥锁保护创建过程
- `delete_treefile` / `mkdir_path`:删除块文件、逐级建目录

**`nbd-server.c`(I/O 路径接线)**
- `setupexport`:treefiles 导出不再打开单个文件(`export` 置 NULL),大小直接取 `filesize`
- `get_filepos`:treefiles 时按偏移现开对应块文件,`maxbytes` 截到块边界,读写循环自然按块跨文件
- `rawexpread` / `rawexpwrite` / `rawexpsplice`:treefiles 时用毕关闭 fd
- `expflush`:treefiles 时改对整个文件系统 `sync()`(不再遍历 NULL 的文件数组)

**`nbdsrv.c`**:`exptrim` 增加 treefiles 分支——TRIM 覆盖到的整块直接删除块文件(man 文档:"Files will be deleted if the corresponding block gets marked as unused")

普通导出(不含 `treefiles = true`)的代码路径全部走原逻辑,未变。
