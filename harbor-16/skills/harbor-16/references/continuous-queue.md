# 连续作业循环（挂机不停 · 零确认）

与 SKILL「连续作业循环」配套。默认：**一直做，不要停、不要问要不要继续。**

## 总流程

```text
做当前题 →（失败则按 skill 自动换仓/新时间戳目录重开，同一 zq* 做到成功）
       → 成功：打 zip + 飞书已提交
       → 立刻领下一题（向威 + 已领取）
       → 重复
       → 飞书无可领题 → 停止
```

## 触发领下一题

当前作业同时满足：

1. delivery-checklist / P0 全过  
2. zip 已写出  
3. 飞书回写成功（`状态=已提交`，见 [feishu-delivery.md](feishu-delivery.md)）  

→ **立刻**查下一题并开做；**禁止**等待用户确认「要不要做下一题」。

## 下一题筛选（硬条件）

| 字段 | 必须值 |
|------|--------|
| **标注员** | **向威** |
| **状态** | **已领取** |

另：须仍待交付（非「已提交」等）。

- **有命中** → 马上新建时间戳目录开做  
- **无命中** → 短报后 **停止**；禁止无题时反复刷飞书 / sleep 轮询  

### 来源优先级

1. 用户本会话给出的 `zq*` 队列（FIFO）——须也是 向威 + 已领取  
2. 飞书：`标注员=向威` 且 `状态=已领取` 的下一条待交付  
3. 都没有 → **挂机循环结束**

## 失败自动续跑（零确认）

| 情况 | Agent 行为（禁止问用户） |
|------|--------------------------|
| baseline/oracle 不过 | 保留旧目录 → 新 `…-YYYYMMDD-HHMM/` → **先 Docker 清理** → 换题/换仓 → 重做 |
| 当前 16-trial batch 未达标 | 固定提示词、复用并重复验证已验证镜像，完整跑下一个 16 容器 batch；不跨批累计 trial。未达标批仅从提交 staging 排除，原始数据和 manifest 必须本地保留 |
| 超时污染整 job | 作废 → **Docker 清理后**重跑（调 timeout/环境后；**不**据此降 level） |
| 同概念约 3 次仍挂 | 换更大工程继续，仍同一作业 ID |
| 本题未成功 | **禁止**跳下一飞书题 |

做到本题飞书「已提交」后，才领下一题。

## 新题启动清单

```text
[ ] 上一题已短报 zip + 飞书已提交（不等确认）
[ ] 查询：标注员=向威 AND 状态=已领取；无 → 停止
[ ] Docker 环境清理（自身网络池/残留容器）——新题/重跑前必做
[ ] 读取领域/子领域/语言/题型
[ ] 新建 …-YYYYMMDD-HHMM/ 并 init
[ ] quality.toml+rewardkit → 校准 → 反复完整 16 路 batch 直到凑齐配额 → zip → 飞书
[ ] 成功后再领下一题；失败则本 ID 自动换仓续跑（每次重跑前同样先清理 Docker）
```

## 禁止

- 交卷后问「要不要做下一题」或停手等回复  
- 失败后问「重跑还是换项目」  
- 本题未成功就领下一飞书题  
- 选非向威 / 非已领取的行  
- 无题可领时刷飞书空等  
- 覆盖旧目录重做（必须新时间戳目录）  
- 未清理本流程残留就并行开 16 个 Docker 容器
- 新题/重跑前不清理自身 Docker 网络池就开跑

## 串行与资源

- **默认一题做完再开下一题**（难度门固定占用 16 个 Docker 容器）  
- **每题/每次重跑前**清理自身 Docker 网络池与残留容器（见 SKILL「Docker 环境清理」）  
- OrbStack 网络/磁盘告警时先清理再开下一题  
- API 限流时不要悄悄降低本题并发；释放资源或等待配额恢复后，仍按固定 16 容器并发重开该 job

## 用户口令

| 用户说 | 行为 |
|--------|------|
| （默认）/ 一直做 / 挂机 / 晚上刷 | 零确认连续做，直到飞书无题 |
| 停 / 先别开新题 / 做完这题停 | 结束循环 |
| 继续 | 再查一次飞书；有则做，无则停（不轮询） |

## 硬阻断（才允许停下来等人）

- 飞书鉴权失败 / 无写权限  
- 缺 API Key  
- Docker/磁盘/配额明显不可用  

说明卡点后等恢复；**策略选择类问题一律自行按 skill 决定，不停不等。**
