## 改动内容

**`nbdsrv.h`** — CLIENT 结构增加每会话 CoW 状态：
- `difffile`：本会话 diff 文件的 fd（-1 表示未启用）
- `difffilename`：diff 文件路径，断开时用于删除
- `difffilelen`：diff 文件数据区当前长度
- `difmap`：块索引表，记录导出每个 4096 字节块在 diff 文件中的位置，-1 表示本会话未写过
- `diff_lock`：保护 diff 文件并发访问（请求在线程池中并行处理）

**`nbd-server.c`** —
- `setup_difffile()`：连接建立（`setupexport` 末尾）时创建 diff 文件。文件名 `<cowdir 或主文件目录>/<主文件名>-<pid>-<序号>.diff`，`O_EXCL` 防冲突；`cowdir` 选项决定目录（缺省用主文件所在目录）；`sparse_cow` 时把文件 truncate 到导出大小、块按原偏移存放（稀疏文件），否则块追加到文件末尾（对应 man page 对两种模式的描述）
- `cowexpwrite()`：写入全部落到 diff 文件，主文件不动；跨块/不对齐写入按 4096 块切分，部分块先读旧内容（diff 优先，否则主文件）再整块写回；`sync`/`fua` 语义同样作用于 diff 文件
- `cowexpread()`：读取时 diff 中已有的块优先返回，其余读主文件
- `rawexpread`/`rawexpwrite`：CoW 客户端分流到上面两个函数，普通导出路径不变（原 `rawexpread` 主体抽为 `masterexpread` 复用）
- `expflush()`：CoW 时一并 fsync diff 文件
- `finalize_client()`：连接断开（正常 DISC 或掉线）时 unlink 并关闭 diff 文件、释放索引表——主文件保持原样

配置校验沿用现有逻辑（`copyonwrite` 与 `splice`/`waitfile` 互斥已在 `parse_cfile` 中拒绝）；`readonly` + CoW 时不创建 diff（写本来就会被拒绝）。TRIM 在 CoW 下维持原有的成功无操作占位行为（代码中原有注释说明）。
