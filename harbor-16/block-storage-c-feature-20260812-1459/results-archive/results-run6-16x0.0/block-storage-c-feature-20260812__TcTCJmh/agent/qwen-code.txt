## 改动

**`nbdsrv.h`** — `CLIENT` 结构补回四个 COW 字段:`difffilename`(diff 文件路径)、`difffile`(fd)、`difffilelen`(非稀疏模式下已追加的页数)、`difmap`(每个 4096 页一项,记录该页数据在 diff 文件中的页号,`(uint32_t)-1` 表示未写过)。

**`nbd-server.c`**:

- `copyonwrite_prepare()`(新增):协商提交时(`commit_client` 里 `setupexport` 之后)为本连接建 diff 文件 —— 有 `cowdir` 用 `cowdir`,否则放主文件同目录,命名 `<目录>/<主文件名>-<客户端>-<pid>.diff`,`O_RDWR|O_CREAT|O_TRUNC` 打开并初始化脏页映射。
- `expwrite()`:COW 导出按 4096 页写入 diff 文件,不进主文件。已脏页就地覆盖;新脏页在 `sparse_cow` 时槽位=页号(稀疏文件),否则追加到 diff 末尾(`difffilelen++`);非整页写先从主文件读回整页再合并写入。`sync`/FUA 语义落在 diff 文件上。
- `expread()`:逐页判断 —— 脏页从 diff 文件读(优先返回新写内容),干净页走原路径读主文件;普通导出行为不变。
- `finalize_client()`:连接断开(正常 DISC 或掉线)时 `unlink(client->difffilename)`,主文件全程只读不碰。

一个顺手修正:`dirname()`/`basename()` 会改写入参,传副本进去,避免 `client->exportname` 被截断(否则无 `cowdir` 时 diff 文件名和 postrun 拿到的文件名都会错)。
