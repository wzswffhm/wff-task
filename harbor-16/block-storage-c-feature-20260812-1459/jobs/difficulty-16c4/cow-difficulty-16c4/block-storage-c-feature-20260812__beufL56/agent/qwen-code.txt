## 问题根源

`nbd-server.c` 里写时复制的整套运行时代码被剥掉了:配置解析(`copyonwrite`/`sparse_cow`/`cowdir`/`waitfile`)还在,但读写路径没有任何 CoW 分支——写直接 `pwrite` 进主文件,读直接读主文件,断开也没有任何清理。对照上游 NetworkBlockDevice/nbd 源码确认后,把缺失的实现按原样恢复。改动仅两个文件:

- **`nbdsrv.h`** — `CLIENT` 结构恢复 4 个字段:`difffilename`、`difffile`、`difffilelen`、`difmap`(页映射表)。
- **`nbd-server.c`** — 恢复 `copyonwrite_prepare()`、`commit_diff()`、`wait_file()`,以及 `expread`/`expwrite`/`expflush`/`finalize_client`/`setupexport`/`commit_client`/SIGUSR1 处理器中的 CoW 分支。

## 恢复后的行为(man 语义)

- **copyonwrite**:连接时在导出文件同目录(或 `cowdir`)建 `<名字>-<客户端>-<pid>.diff` 临时文件和 4096 字节页映射表;写一律进 diff 文件(非整页先读原页叠加再落 diff,`sync`/`fua` 也作用在 diff 上);读优先取 diff 里的脏页,其余读主文件;断开时 `unlink` diff 文件,主文件保持原样。`WRITE_ZEROES` 走同一写路径;TRIM 在 CoW 下为无害空操作(上游原样)。
- **sparse_cow**:稀疏模式下页号即 diff 内偏移;非稀疏模式新写块追加到 diff 末尾并在映射表登记(即 man 里说的 "map every newly written block to the end")。
- **cowdir**:决定 diff 文件落哪个目录。
- **waitfile**(同样被剥掉的选项,与 CoW 共用整套机制):SIGUSR1 前只允许写(进 diff)、拒绝读未写区域;收到信号后把 diff 合并进主文件再切换为正常服务。man 承诺"合并完成后删除 diff 文件"但上游代码漏了这步——补了一行 `unlink`(这是相对上游唯一的语义增补)。
