## 改动内容

**`nbdsrv.h`** — 给 `CLIENT` 结构加了 4 个字段（名字与已有单测 `tests/code/trim.c` 引用的保持一致）：
- `difffilename` / `difffile`（fd，未启用时为 -1）/ `difffilelen` / `difmap`（导出块号 → diff 文件位置的映射）

**`nbd-server.c`** — 核心实现：
- `setup_cow()`：连接建立时按 `cowdir`（或主文件所在目录）创建每连接独立的 `.diff` 文件并分配块映射；`sparse_cow` 时把 diff 文件 `ftruncate` 到导出大小做成稀疏文件，否则块按追加方式分配。
- `cleanup_cow()`：挂进 `finalize_client()`，连接结束（收到 `NBD_CMD_DISC` 或 socket 断开）时删除本次会话的 diff 文件、释放映射，主文件保持原样。
- 写路径 `rawexpwrite_cow` + `cow_write_block`：写入不进主文件，只进 diff；部分覆盖的块做"读旧块—合并—写整块"（旧内容按是否已脏分别从 diff 或主文件取）。
- 读路径 `rawexpread_cow` + `cow_read_master`：diff 里已有的块优先从 diff 返回，其余读主文件。
- `expflush` 同时 fsync diff 文件；协议错误退出路径也补了清理；只读导出跳过建 diff（写本来就会被拒）。
- 用之前初始化了却没用的 `export_lock` 读写锁保护共享的块映射，写串行、读并发。
