## 改动内容

**`nbdsrv.h`** — `CLIENT` 结构补上 COW 会话状态(与 `tests/code/trim.c` 期望的字段名一致):
- `difffilename`(diff 文件路径)、`difffile`(diff 文件 fd)、`difffilelen`(非 sparse 模式下已分配页数)、`difmap`(每 4KiB 页 → diff 文件页号的映射,`-1` 表示未写)

**`nbd-server.c`**
- 新增 `copyonwrite_prepare()`:连接建立时在 `cowdir`(未配置则取导出文件所在目录)创建 `<文件名>-<客户端IP>-<pid>.diff`,并初始化页映射;在 `commit_client()` 里 `setupexport()` 成功后对 `F_COPYONWRITE` 导出调用
- `expwrite()`:COW 导出按 4KiB 页写入 diff 文件,主文件不动;部分页先读回原页内容再合并写入;`sparse_cow` 时页号 1:1 映射(sparse 文件),否则追加到 diff 文件末尾;`F_SYNC`/FUA 同步的是 diff 文件
- `expread()`:逐页查 `difmap`,命中则从 diff 文件读(新写内容优先),否则回落到主文件
- `expflush()`:COW 导出 fsync diff 文件
- `finalize_client()`:连接结束(NBD_CMD_DISC 或掉线)时 `unlink` 本次会话的 diff 文件
- `setupexport()`:COW 模式下主文件以只读打开成功时不再降级为 `F_READONLY`(配合 `cowdir` 导出无写权限目录里的文件)
- diff 文件名用 `g_path_get_dirname/g_path_get_basename` 生成,避免 POSIX `dirname(3)` 原地修改 `exportname`

TRIM 对 COW 导出原本就是显式 no-op(`exptrim` 已有处理),保持不变;`copyonwrite` 与 `splice`/`waitfile` 的互斥校验原本就在配置解析里。
