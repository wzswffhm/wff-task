## 改动

**`treefiles.c`(新实现,对应 `treefiles.h` 声明的 4 个函数)**
- `construct_path`:树的布局只由导出大小和偏移决定——按 4096 字节(TREEPAGESIZE)分块,每级目录最多 1024(TREEDIRSIZE)个条目,大小决定嵌套深度;偏移映射为 `exportname/TREEXXXX/.../FILEXXXX`
- `open_treefile`:按需打开/创建对应块文件(互斥锁保护创建竞争);新建文件扩到 4096 字节(稀疏);只读打开不存在的块时用已 unlink 的零填充临时文件,读不会凭空造文件
- `delete_treefile` / `mkdir_path`:删块文件、递归建目录

**`nbd-server.c`**
- `get_filepos`:treefiles 分支——按块打开文件,I/O 钳制在块边界内,交错的请求由外层 `_fully` 循环逐块推进
- `rawexpread`/`rawexpwrite`/`rawexpsplice`:treefiles 时每次操作后关闭 fd(句柄全按需,不预开)
- `setupexport`:treefiles 导出 `export=NULL`、大小取 `filesize`;文件/目录首次写入时自动创建
- `expflush`:treefiles 分支(无持久句柄,非只读时 `sync()`)
- `parse_cfile`:按 man 文档要求,`treefiles` 未配 `filesize` 时启动即报错

**`nbdsrv.c`**
- `exptrim`:TRIM 范围内被完整覆盖的块,其文件直接删除(man 所述 "marked as unused 即删文件");部分覆盖的边缘块保留

普通导出路径未动(所有分支都以 `F_TREEFILES` 前置判断)。另外补回了 `tests/run/simple_test`、`cwrap_test` 丢失的可执行位,否则测试框架跑不起来。
