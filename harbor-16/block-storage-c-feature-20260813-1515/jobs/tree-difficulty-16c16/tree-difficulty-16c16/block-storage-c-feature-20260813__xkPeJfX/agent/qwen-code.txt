## 改动内容

**`treefiles.c`(原本是 "not implemented" 的空壳)** — 实现树布局原语:
- `construct_path()`:把导出内偏移映射成 `exportname/TREEXXXX/.../FILEXXXX` 路径。每块固定 4096 字节(TREEPAGESIZE),每目录最多 1024 项(TREEDIRSIZE),子目录层数按 filesize 自动计算(≤4MB 0 层、≤4GB 1 层、≤4TB 2 层……)
- `mkdir_path()`:递归创建父目录(容忍并发 EEXIST)
- `open_treefile()` / `delete_treefile()`:按需打开/创建块文件;删除块文件(TRIM 用)

**`nbd-server.c`** — 接入服务器:
- `setupexport`:F_TREEFILES 分支——校验 filesize 必须配置、创建(或只读时容忍缺失)根目录、以 filesize 作为导出大小;块文件按需打开,不再落到单文件
- 读路径 `treeexpread`:块文件不存在读作全零,文件比块短的部分补零,跨块读自动分块续读
- 写路径 `treeexpwrite`:按需建目录建文件,支持 F_SYNC/FUA 语义
- `expflush`:递归 fsync 整棵文件树
- 配置校验:treefiles 必须配 filesize;与 splice、waitfile 互斥(启动时报错)

**`nbdsrv.c`** — `exptrim`:treefiles 导出的 TRIM 直接删除被 trim 块的块文件,之后读回为零。`nbdsrv.h` 给 CLIENT 加了目录创建锁。

**`tests/code/treefiles.c`** — 新增单元测试,覆盖 0/1/2 层树的路径映射、按需创建、删除、mkdir_path。
