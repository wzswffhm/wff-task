## 改动

**核心实现 — `treefiles.c`（原来是空壳）**
- 数据布局:导出名变成一棵文件树的根目录,每个叶子文件存一个 4096 字节块(`TREEPAGESIZE`),每个目录最多 1024 个条目(`TREEDIRSIZE`)。树的层数由 `filesize` 决定(≤4MiB 单层,≤4GiB 两层,以此类推),偏移量按块号映射到 `根/目录/.../文件`,读写路径一一对应
- 实现了头文件里声明的 `construct_path`、`mkdir_path`、`open_treefile`、`delete_treefile`,另加 `trim_treefiles` 供 TRIM/WRITE_ZEROES 用

**服务端的接线 — `nbd-server.c` / `nbdsrv.c` / `nbdsrv.h`**
- 配置校验:treefiles 必须给 `filesize`(树没法自动探测大小);与 multifile 同时给时 treefiles 优先(man 文档规定);与 copyonwrite/waitfile/splice/temporary 组合直接在配置解析时报错
- `setupexport` 增加 treefiles 分支:校验/创建根目录,大小取 `filesize`;块文件按需打开(写时 `O_CREAT` 连同目录一起建)
- 读写路径:块文件按需 open/pread|pwrite/close;不存在的块读回全零;跨块请求由原有循环自然分片;F_SYNC/FUA 语义保留
- TRIM/WRITE_ZEROES:整块被覆盖就删文件(man 文档说的 "marked as unused 就删"),部分覆盖只把对应区间写零
- CLIENT 增加 `tree_lock`,多线程(dontfork)模式下串行化文件/目录创建
