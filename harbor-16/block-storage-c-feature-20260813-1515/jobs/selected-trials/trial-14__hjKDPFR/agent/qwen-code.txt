## 改动内容

**`treefiles.c`**(原来只有一行 "not implemented" 的桩)——完整实现:

- `construct_path` / `mkdir_path` / `open_treefile` / `delete_treefile`(即 `treefiles.h` 里原本声明的四个函数),另加三个 I/O 辅助函数:
  - `treeexpread`:按块打开文件读取;没写过的块(无文件)读回全 0,短文件/末尾不完整块自动补 0
  - `treeexpwrite`:按块按需创建目录和文件写入,遵守 `F_SYNC`/FUA/`F_FLUSH`(文件写完即关,关前同步),写超出 filesize 的部分自动截断
  - `treetrim`:整块被 trim → 删除块文件;部分 trim → 在块文件上打洞
