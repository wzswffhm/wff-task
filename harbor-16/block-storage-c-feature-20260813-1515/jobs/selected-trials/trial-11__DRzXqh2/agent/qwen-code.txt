## 改动

**`treefiles.c`(核心实现,原来是空的)**
- 偏移 → 块文件路径:块号按 1024 进制拆位,高位是 `TREEXXXX` 目录、低位是 `FILEXXXX` 文件,嵌套层数随 `filesize` 增长(≤4MiB 一层、≤4GiB 两层……),每层目录 ≤1024 个条目,块文件固定 4096 字节——与 man 页一致
- `construct_path` / `mkdir_path` / `open_treefile` / `delete_treefile`(沿用 `treefiles.h` 里已有的接口签名),目录按需懒创建

**`nbd-server.c`**
- `setupexport()`:treefiles 分支——强制要求 `filesize`(无法自动探测大小)、创建根目录、若导出名已被普通文件占用则明确报错;块文件按请求开/关,不长期占 fd
- `treeexpread/treeexpwrite`:读写按块边界切分后落到对应块文件;没写过的块读回全零(不会凭空建文件);写入时自动建目录/文件,末块不足 4096 时按实际长度截断;支持 FUA/sync
- `expflush` 对 treefiles 直接成功(数据写入时已同步);配置解析阶段拒绝 treefiles+copyonwrite/waitfile/splice 组合,treefiles 优先于 multifile(man 页要求)

**`nbdsrv.c`** — `exptrim`:整块被 TRIM 时删除对应块文件(man 页:"block 标记 unused 时删除文件");部分 TRIM 则对块文件打洞
