## 改动

**`treefiles.c`(新实现)**——四个基础函数:
- `construct_path`:把导出偏移换算成树内路径。设备按 4096B(TREEPAGESIZE)分块,每块一个文件;目录扇出 1024(TREEDIRSIZE),层数按 `filesize` 自动推导,块号按 1024 进制拆成 `%04X` 命名的目录/文件名(如 4MB → `nbd.tree/0000`…`03FF`;5MB → `nbd.tree/0001/0000`)
- `mkdir_path`:mkdir -p 式建目录
- `open_treefile`:按偏移打开块文件,不存在时持锁建目录树并创建
- `delete_treefile`:块标记为未用时删除对应文件

**`nbd-server.c`(接入)**:
- `setupexport_treefiles`:建根目录、`exportsize = filesize`,块文件按需开/关不预占 fd;清掉 `F_MULTIFILE`(man 页:treefiles 优先)和 `F_WAIT`
- 读:整块缺失或部分缺失一律读作 0;写:按需创建块文件,跨块请求由原有 `rawexp*_fully` 循环按块边界拆分;两者都支持 FUA/sync
- TRIM / WRITE_ZEROES:整块覆盖的文件直接删除(man 页:"Files will be deleted if the corresponding block gets marked as unused"),部分覆盖的块写零
- FLUSH 对 treefiles 直接返回 0;`commit_client` 初始化每客户端的建树锁

**配置校验**(`parse_cfile`):treefiles 必须配 `filesize`、不能与 `splice` 同用,否则启动时报错退出(和现有 copyonwrite+splice 的校验同款)。

另外修了个环境小问题:`tests/run/simple_test` 和 `cwrap_test` 丢了可执行位,`make check` 因此全挂,已 `chmod +x`。
