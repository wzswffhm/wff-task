## 实现

**`treefiles.c` / `treefiles.h`**(原先是 stub):
- 树的深度由 `filesize` 决定:取最小的 d 使 `1024^d × 4096 ≥ filesize`;块号按 1024 进制拆成 d 位,映射为 `exportname/TREE%04d/.../FILE%04d`(4 MiB → 1 层 1024 个 FILE;8 MiB → `TREE0000`、`TREE0001` 两个子目录)
- `construct_path` / `mkdir_path` / `open_treefile`(按需创建目录和块文件,带 mutex 串行化创建)/ `delete_treefile`

**`nbd-server.c` / `nbdsrv.c` 接入**:
- `setupexport`:treefiles 导出不打开单一大文件,只建根目录、用配置的 `filesize` 作为设备大小(只读导出允许目录尚不存在,读全零)
- `rawexpread` / `rawexpwrite`:按 4 KiB 块切分请求;写时按需建块文件,不存在的块读作全零,短文件/空洞补零
- `exptrim`:整块被 trim → 删除对应块文件;部分块 → 打洞(man 文档说"块被标记未使用时删除文件")
- `expflush`:只 fsync 上次 flush 以来写脏的块文件(脏集跟踪)。最初我对每次 flush 遍历整棵树做 fsync,结果一致性测试 trace 里 1191 个 FLUSH 直接把服务器拖死,改成脏集后通过
- `parse_cfile`:treefiles 必须配 `filesize`,与 copyonwrite/waitfile/splice/temporary 组合报错,与 multifile 同配时按 man 文档以 treefiles 优先

普通导出(不带 treefiles)的代码路径没有改动。
